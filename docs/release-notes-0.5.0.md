# Julia Time 0.5, our first public release

Julia Time is a free game that teaches you Julia. You solve a lab mystery by typing short lines of real Julia and reading what comes back. The mystery is made up. The Julia, and the data, are real.

Watch the [trailer](https://itchyshin.github.io/Julia-Time/trailer.mp4) or see [the webpage](https://itchyshin.github.io/Julia-Time/). It is for graduate students, researchers and teachers. You do not need to know R or Python, but if you do, you will see the matching line beside every new one.

## What is in it

- Six lessons and six chapters. Each lesson is a short practice round with one new idea; each chapter then uses that idea on the real case, *The Case of the Missing Fleas*.
- An optional target range: eleven levels and a boss, where you write one line that picks the right jars.
- R and Python beside every new line, each with its own switch, so you can hide what you do not need.
- Help that names your slip. When your code goes wrong, the message says which mistake it saw and how to fix it.
- No scores. Your place is saved, nothing is locked, and the whole course takes about 4 hours.

## How to install

Download the ZIP, install Julia 1.10 once, then double-click one launcher file. Full steps, with the Julia download links for Mac and Windows, are in [the installation guide](https://github.com/itchyshin/Julia-Time/blob/main/docs/install.md).

We tested this release on macOS. We have not yet run this ZIP on Windows or Linux; if anything breaks on yours, please tell us.
