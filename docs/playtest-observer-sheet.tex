{\Large\bfseries Julia Time playtest observer sheet: first session in Lesson 1}\\[-2pt]
\textit{10 to 15 minutes, no-rescue session. This sheet tests the game, not the player. A first session lands in Lesson 1, a practice notebook called logbook that is made up for training. It is not the case, so record nothing about the case. Tell the player what is recorded (this sheet, no names) and that they can stop at any time. Ask permission before any recording. Guide: docs/playtest-observer-guide.md.}

\vspace{3pt}
\textbf{Before the player arrives}\\
Date: \rule{0.14\linewidth}{0.3pt}\quad Observer: \rule{0.20\linewidth}{0.3pt}\quad Player id (no names): \rule{0.20\linewidth}{0.3pt}\\
Game version (the ZIP name, Julia-Time-...): \rule{0.22\linewidth}{0.3pt}\quad Julia version (\texttt{julia --version}): \rule{0.15\linewidth}{0.3pt}\\
System: \checkbox\ macOS \quad \checkbox\ Windows \quad \checkbox\ Linux \qquad Started from: \checkbox\ launcher \quad \checkbox\ terminal\\
Player type: \checkbox\ new coder \quad \checkbox\ R or Python user \quad \checkbox\ pair \qquad Browser and start time: \rule{0.25\linewidth}{0.3pt}\\
Setup: game running, browser open on the Case Board, Lesson 1 not started (the button says Start Lesson 1, not Continue).

\vspace{3pt}
\textbf{Say only:} ``Please play the game without help. If you get stuck, say aloud what you expected to happen. I am testing the game, not you, so I will not teach or point things out.''\\
\textit{Do not demonstrate code, name a button, or explain Julia while the player is deciding what to do. On-screen help is not rescue: let the player use Hint, Look closer, the Show R and Show Python notes, error messages and the optional intro, and record each use. If asked for help, say only ``What would you try?'' and write the question down. If the player is truly stuck, note the time and wait 2 minutes. Then stop the session and record where their own next action became unclear. Stop at 15 minutes or when Lesson 1 finishes.}
