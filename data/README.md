# data/

Toto's water fleas (*Daphnia*), `water_fleas.csv`: **SIMULATED data, generated by a seeded
simulator** (`water_fleas.jl`), **not real counts**.

## Columns

| column  | type    | meaning                                                              |
|---------|---------|-----------------------------------------------------------------------|
| `pond`  | String  | one of `"north"`, `"south"`, `"east"`, `"west"`                       |
| `jar`   | Int     | jar number within a pond, 1-12 (48 rows total, ordered pond-major)    |
| `count` | Int     | Daphnia counted in that jar; Poisson, pond mean differs on the log scale |
| `temp`  | Float64 | water temperature in that jar, degrees C (roughly 14-24, 1 decimal)   |

`count` has a mild positive dependence on `temp`; pond means are well separated (north highest,
west lowest) so filtering/grouping levels have something clear to find.

## Regenerating

```
julia --project=. data/water_fleas.jl
```

Uses `seed = WATER_FLEAS_SEED` (`MersenneTwister`) — running it again overwrites
`water_fleas.csv` byte-identically.

## House rule

Any level or screen that shows these numbers must label them **simulated** — they are not real
water flea counts.

## starter_ponds.csv

Starter table for the optional "Your own data" stage, for students with no data of their own.

**SIMULATED data, generated by a seeded script** (`starter_ponds.jl`), **not real counts**.

| column       | type    | meaning                                                              |
|--------------|---------|-----------------------------------------------------------------------|
| `pond`       | String  | pond code, `P01` to `P60` (60 rows, one per pond survey)              |
| `site`       | String  | `"north"` or `"south"`                                                |
| `treatment`  | String  | `"shaded"` or `"open"`                                                |
| `water_temp` | Float64 | water temperature, degrees C, 1 decimal; **two values are empty on purpose** |
| `frogs`      | Int     | frogs counted at the pond                                             |

Shaded ponds are made about 2 degrees cooler and have somewhat more frogs, so comparing two
groups has something to find. The two empty `water_temp` cells let students meet a missing value
in a safe place.

### Regenerating

```
julia --project=. data/starter_ponds.jl
```

Uses `seed = STARTER_PONDS_SEED` (`MersenneTwister`); running it again overwrites
`starter_ponds.csv` byte-identically.

Any screen that shows these numbers must label them **simulated**.

### Using your own CSV

Copy your file into this folder (`data/`), next to `starter_ponds.csv`. In the game, step "Read the table"
shows `data = CSV.read("data/starter_ponds.csv", DataFrame)`. Change the file name in the quotes to yours.
The Choose button in the game is a fallback if typing the read does not work. The starter table is
SIMULATED. Your own file stays on your computer.
