    One row, one jar
    
      
    A table has rows and columns. Each row is one jar; each column is one detail. Julia selects them in this order: rows first, columns second.
    
      
    jars[rows, columns]
    
      
    Try the first three rows: type jars[1:3, :]. The range 1:3 means rows 1 through 3; the final : means all columns. These are practice records, not necessarily Toto’s batch.
