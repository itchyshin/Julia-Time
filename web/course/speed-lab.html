Curious how the same bootstrap runs in three languages?

What this page is for: after you finish the mystery, you can ask one fair question on this computer: do Julia, R, and Python give the same answer to the same supplied bootstrap calculation, and how long does each take here?

  1. Step 1: confirm the answers agree. The lab runs a fixed calculation in all three languages and checks the returned values.
  2. Step 2: time those matching calculations. This unlocks only when Step 1 passes, so we never compare unlike answers.
  3. Step 3: read one local report. It describes this computer and these settings; it is not a claim that a language always wins.

A bootstrap repeatedly resamples a fixed dataset and recalculates one summary. If a language is missing, the page says so; the Missing Fleas mystery is still complete. Each language has a 30-second total limit across both fixed workloads.

You do not need to do this to learn Julia or finish the case. Leave this page if you would rather continue the mystery. This laboratory is only for comparing one small calculation on this computer.
