Optional after the mystery

How fast is Julia on your own computer?

What this page is for: after you finish the mystery, you can time six small, fixed calculations in Julia, R and Python on this computer, and then time a few lines of your own Julia code.

  1. Answers first. For each calculation the lab checks that the answers agree across the languages before timing anything, so we never time answers that do not match.
  2. Then the clock. One warm-up run, then the median of three timed runs, one language at a time. Every number you see was measured here, just now. Nothing is remembered or typed in by us.
  3. Missing a language? The page says "not installed, not timed" and carries on. R and Python run only the fixed files that come with Julia Time; they never run code you type.
You do not need to do this to learn Julia or finish the case. The numbers describe this computer and these small loops. They are not a claim about every program or every computer.

Six fixed calculations

Before you start: leave the Julia Time terminal running. Each calculation takes roughly 5 to 30 seconds to check and time; all six take a few minutes.

Time your own code

Type a few lines of Julia. They run in the same sandbox as the lessons, twice in a row, with one 5-second limit for both runs together. You will see the two times separately. Your lines run inside a function, the way fast Julia code is written.
