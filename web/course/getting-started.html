Julia Time is a local browser game in which you use real Julia to investigate a simulated water-flea mystery.

You do not need to build the game, create a GitHub account, find a package in a registry, or install R or Python.

Set up Julia Time

Already downloaded Julia Time? You are now in the bundled local guide. This guide can be shared as a static page, but the mystery itself runs on your own laptop after you start the local lab. If you reached this guide before downloading the folder, return to the public Julia Time README first.

One simple distinction

What is Julia Time?

Julia Time

This supplied folder and learning game. It runs locally on your own laptop.

Julia

Julia is the programming language. It runs the game and the small investigation moves you write.

R and Python

They are optional reference languages only. You do not need either one for this build of the mystery.

A useful technical detail, without homework: the folder is a local Julia project called JuliaTime. Do not run Pkg.add("JuliaTime"); the one-time setup prepares the folder’s own declared packages.

The one computer step

Open a terminal in the Julia Time folder

A terminal is simply the small text window that can run a command in a folder. The commands below only work when that window is in the extracted Julia Time folder—not in Downloads generally, and not in a different project.

Mac

In Finder, open the extracted Julia Time folder. Control-click its background and choose New Terminal at Folder (or open Terminal and drag the folder onto it after typing cd ).

Windows

In File Explorer, open the extracted Julia Time folder, then right-click its background and choose Open in Terminal.

Linux

In your file manager, open the extracted Julia Time folder, right-click its background and choose Open in Terminal (or open a terminal and type cd followed by the folder path). Then run chmod +x tools/setup/launch-linux.sh once and tools/setup/launch-linux.sh to play.

Or skip the terminal

Double-click Play-Julia-Time-Mac.command (Mac) or Play-Julia-Time-Windows (Windows) at the top of the folder; they call tools/setup/launch-macos.command and tools/setup/launch-windows.cmd. You do not need Julia on PATH: these helpers also find the usual Julia 1.10 installation folder. Keep the game window open while you play.

Do not guess whether it worked: only call the game ready when the Case Board says Julia is ready. If it does not, return here and use the recovery steps below.

Set up once, before the meeting

What you need

Your laptop, the supplied Julia Time archive, Julia 1.10.x, and an internet connection. Internet is needed to download Julia and for the first course setup, when Julia prepares this folder’s packages.

  1. Extract the supplied archive somewhere you can find again. On Windows, right-click the ZIP and choose Extract All, then open the inner folder that contains Play-Julia-Time-Windows. You do not need to clone a repository or sign in anywhere.
  2. Install Julia 1.10.x, not the newest Julia: Windows julia-1.10.12-win64.exe; Mac with Apple Silicon julia-1.10.12-macaarch64.dmg; Intel Mac julia-1.10.12-mac64.dmg (Apple menu, About This Mac, tells you which); anything else from the official Julia long-term-support download page. A newer Julia already installed is fine; the launchers find the 1.10 beside it. If the Windows installer asks, choose Install for me only; that needs no administrator rights. A Chromebook, tablet, or phone cannot run Julia Time.
  3. Double-click one file. Windows: Play-Julia-Time-Windows. Mac: Play-Julia-Time-Mac.command. The first time, it runs the one-time check below for you (several minutes), then opens the Case Board. Keep its window open while you play.
If your computer asks first: on Windows, a warning about an unknown publisher or "Windows protected your PC" means choose More info, then Run anyway (or Run). On a Mac, "cannot verify" means click Done, open System Settings, Privacy & Security, click Open Anyway next to the file, then double-click it again; if asked whether Terminal may use your Downloads folder, click Allow.

Prefer a terminal, or need to recover? The blocks below are the same one-time check typed by hand. On Windows, tools/setup/setup-windows.cmd runs it on its own too.

Choose your platform deliberately: choose the block whose title exactly matches your terminal. Mac/Linux and Windows commands are different; do not copy a command meant for another platform.

Mac or Linux Terminal: one-time check 
JULIA_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 julia --startup-file=no --history-file=no --project=. check_setup.jl
Windows Command Prompt: one-time check 
set JULIA_NUM_THREADS=4
set OPENBLAS_NUM_THREADS=1
julia --startup-file=no --history-file=no --project=. check_setup.jl
Windows PowerShell: one-time check 
$env:JULIA_NUM_THREADS = "4"
$env:OPENBLAS_NUM_THREADS = "1"
julia --startup-file=no --history-file=no --project=. check_setup.jl

Setup is complete only when the terminal says OK — Julia Time is ready.

How to play without hunting around

Your code is the investigation move.

  1. Read the brief. Each chapter puts the question, the relevant data, and the required result in view before you write.
  2. Inspect the evidence. Look at the visible table, its column names, and the records you need to reason about.
  3. Write a small Julia move. The editor starts empty (or restores your own earlier typing). You are not expected to invent a whole answer from nothing.
  4. Run it and read what happened. Julia returns the actual result. A successful move explains both what the code did and what it does—and does not—establish about the case.
  5. Use help when you want it. Help me start gives a small nudge first. Depending on the chapter, it can also offer a code shape, an optional full solution, or a different-data practice example. It is help, not a test.
  6. Return to the Case Board. When browser storage is available, it saves your evidence and points to the next available move. It is not a grade or leaderboard.

If something goes wrong

Take the shortest safe next step.

Show recovery help
julia is not found, or the version is wrong
On Windows, first try the supplied double-click setup helper: it also checks the usual Julia 1.10 installation folder. Otherwise install or select Julia 1.10.x, open a new terminal, and run the one-time check again. On a Mac, if Julia is installed but the terminal cannot find it, use /Applications/Julia-1.10.app/Contents/Resources/julia/bin/julia in place of julia.
JULIA_TIME_NOT_READY
Run the one-time check_setup.jl command first.
SERVER_START_FAILED
Close an earlier Julia Time terminal, then try again—or ask the facilitator for help. Do not kill unrelated programs.
The browser cannot connect
Keep the Julia Time terminal open and visit the exact local address above. On the Case Board, choose Reconnect to Julia if it appears.
Still stuck
Send the facilitator your operating system and the final 10 terminal lines. Your browser-saved drafts should remain in this browser.
