How to play

How to play

Julia Time is a game that runs on your own computer. You investigate a made-up lab mystery by typing short lines of real Julia. Julia is a computer language; you do not need to know it yet.

You do not need to build the game, create a GitHub account, or install R or Python.

Open the Board

Your code is the move. Five moves, every time.

The game has six steps. Each step is a practice Lesson, then a Chapter on the real case. In every round you make the same five moves.

  1. Read the question. The question, the table you will use and the result you need are on the screen before you type.
  2. Type a line of Julia. Some tasks start with a line for you to change. Others start empty. Nobody asks you to write a whole program from nothing.
  3. Press Run and read what comes back. It is real Julia. If there is a mistake, the message says which line and what to look at.
  4. Ask for help when you want it. In a lesson, Hint 1: the idea gives a small idea and Hint 2: the shape of the line shows the shape. After two misses, Show me the line shows the line to type. In a chapter, Hint: the idea or Show a starter line gives you one piece of help. The hint comes after a miss, the starter line after two. Help costs nothing and nothing is scored.
  5. Press Next. The Board saves your place and points to the next step. It is not a grade or a leaderboard.
Set up Julia Time (only if the Board says Julia is not running)

One simple distinction

What is Julia Time?

Julia Time is a game on your own laptop. You can share this page as a static page, but the mystery itself runs on your own laptop after you start the local lab. If you reached this page before downloading the folder, go back to the Julia Time README on GitHub first.

Julia Time

This supplied folder and learning game. It runs locally on your own laptop.

Julia

Julia is the programming language. It runs the game and the small investigation steps you write.

R and Python

They are optional reference languages only. You do not need either one for this build of the mystery.

One technical detail (nothing to do): the folder is a local Julia project called JuliaTime. Do not run Pkg.add("JuliaTime"); the one-time setup prepares the folder’s own declared packages.

The one computer step

Open a terminal in the Julia Time folder

A terminal is simply the small text window that can run a command in a folder. The commands below only work when that window is in the extracted Julia Time folder, not just anywhere in Downloads, and not in a different project.

Mac

In Finder, open the extracted Julia Time folder. Control-click its background and choose New Terminal at Folder (or open Terminal and drag the folder onto it after typing cd ).

Windows

In File Explorer, open the extracted Julia Time folder, then right-click its background and choose Open in Terminal.

Linux

In your file manager, open the extracted Julia Time folder, right-click its background and choose Open in Terminal (or open a terminal and type cd followed by the folder path). Then run chmod +x tools/setup/launch-linux.sh once and tools/setup/launch-linux.sh to play.

Or skip the terminal

Double-click Play-Julia-Time-Mac.command (Mac) or Play-Julia-Time-Windows (Windows) at the top of the folder; they call tools/setup/launch-macos.command and tools/setup/launch-windows.cmd. You do not need Julia on PATH: these helpers also find the usual Julia 1.10 installation folder. Keep the game window open while you play.

Do not guess whether it worked: only call the game ready when the Board says Julia is ready. If it does not, return here and use the recovery steps below.

Set up once, before you play

What you need

Your laptop, the supplied Julia Time archive, Julia 1.10.x, and an internet connection. Internet is needed to download Julia and for the first course setup, when Julia prepares this folder’s packages.

  1. Extract the supplied archive somewhere you can find again. On Windows, right-click the ZIP and choose Extract All, then open the inner folder that contains Play-Julia-Time-Windows. You do not need to clone a repository or sign in anywhere.
  2. Install Julia 1.10.x, not the newest Julia: Windows julia-1.10.12-win64.exe; Mac with Apple Silicon julia-1.10.12-macaarch64.dmg; Intel Mac julia-1.10.12-mac64.dmg (Apple menu, About This Mac, tells you which); anything else from the official Julia long-term-support download page. A newer Julia already installed is fine; the launchers find the 1.10 beside it. If the Windows installer asks, choose Install for me only; that needs no administrator rights. A Chromebook, tablet, or phone cannot run Julia Time.
  3. Double-click one file. Windows: Play-Julia-Time-Windows. Mac: Play-Julia-Time-Mac.command. The first time, it runs the one-time check below for you (several minutes), then opens the Board. Keep its window open while you play.
If your computer asks first: on Windows, a warning about an unknown publisher or "Windows protected your PC" means choose More info, then Run anyway (or Run). On a Mac, "cannot verify" means click Done, open System Settings, Privacy & Security, click Open Anyway next to the file, then double-click it again; if asked whether Terminal may use your Downloads folder, click Allow.

Prefer a terminal, or need to recover? The blocks below are the same one-time check typed by hand. On Windows, tools/setup/setup-windows.cmd runs it on its own too.

Choose your platform carefully: pick the block whose title exactly matches your terminal. Mac/Linux and Windows commands are different; do not copy a command meant for another platform.

Mac or Linux Terminal: one-time check 
JULIA_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 julia --startup-file=no --history-file=no --project=. check_setup.jl
Windows Command Prompt: one-time check 
set JULIA_NUM_THREADS=4
set OPENBLAS_NUM_THREADS=1
julia --startup-file=no --history-file=no --project=. check_setup.jl
Windows PowerShell: one-time check 
$env:JULIA_NUM_THREADS = "4"
$env:OPENBLAS_NUM_THREADS = "1"
julia --startup-file=no --history-file=no --project=. check_setup.jl

Setup is complete only when the terminal says OK: Julia Time is ready.

Each time you play

Start the local lab

In the same folder, choose the command for your terminal and keep that terminal window open while you play:

Use the same terminal type you chose for setup: Mac/Linux and Windows commands are different.

Mac or Linux Terminal: start the local lab 
JULIA_NUM_THREADS=4 OPENBLAS_NUM_THREADS=1 julia --startup-file=no --history-file=no --project=. run.jl
Windows Command Prompt: start the local lab 
set JULIA_NUM_THREADS=4
set OPENBLAS_NUM_THREADS=1
julia --startup-file=no --history-file=no --project=. run.jl
Windows PowerShell: start the local lab 
$env:JULIA_NUM_THREADS = "4"
$env:OPENBLAS_NUM_THREADS = "1"
julia --startup-file=no --history-file=no --project=. run.jl

The browser should open the Board. If it does not, enter the address the terminal printed after "Julia Time is running at"; it is usually:

http://127.0.0.1:8000/course/index.html

When you finish, return to the terminal and press Enter or Ctrl-C to stop the local game.

If something goes wrong

Take the shortest safe next step.

Show recovery help
Julia is not found, or it is the wrong version
On Windows, first try the supplied double-click setup helper: it also checks the usual Julia 1.10 installation folder. Otherwise install or select Julia 1.10.x, open a new terminal, and run the one-time check again. On a Mac, if Julia is installed but the terminal cannot find it, use /Applications/Julia-1.10.app/Contents/Resources/julia/bin/julia in place of julia.
The launcher says the one-time setup has not finished JULIA_TIME_NOT_READY
Run the one-time check_setup.jl command first.
The launcher could not start the game SERVER_START_FAILED
Close an earlier Julia Time terminal, then try again, or ask the facilitator for help. Do not kill unrelated programs.
The browser cannot connect
Keep the Julia Time terminal open and visit the exact local address above. On the Board, press Reconnect if it appears.
Still stuck
Send the facilitator your operating system and the final 10 terminal lines. Your browser-saved drafts should remain in this browser.
