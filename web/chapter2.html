Words at the point you need them
groupby
Makes one group of records for each value in a column.
:tray_id
Names the tray_id column. This colon form is a column name here, not : indexing all rows.
combine
Builds a new summary table from each group.
nrow
Counts the rows in a group.
=>
Pairs an operation with a result name, such as nrow => :n.
sum
For Boolean values, counts true values: true contributes 1 and false contributes 0.

Rate parts: detected_n is the numerator (recorded detections); n is the denominator (all jars in that tray). detected_n ./ n divides the matching entries tray by tray.

Other Julia, R and Python ways

Julia is the runnable language here. For these complete Boolean records, mean is another way to calculate the detected proportion: true contributes 1 and false contributes 0.

Julia alternative: combine(groupby(jars, :tray_id), nrow => :n, :detected => sum => :detected_n, :detected => mean => :rate)
Base R: aggregate(detected ~ tray_id, jars, function(x) c(n = length(x), detected_n = sum(x), rate = sum(x) / length(x)))
R (dplyr): dplyr::summarise(dplyr::group_by(jars, tray_id), n = dplyr::n(), detected_n = sum(detected), rate = detected_n / n)
Python (pandas): jars.groupby("tray_id", as_index=False).agg(n=("detected", "size"), detected_n=("detected", "sum")).assign(rate=lambda x: x.detected_n / x.n)

These calculate the same counts and proportions when detected has no missing values. Base R's aggregate form stores the three summary values together in a matrix column; its table layout differs. These examples are not a general missing-data policy.
